PEQUITAS - FRONTEND GA6-220501096-AA4-EV01 / EV02 / EV03

Descripción:
Frontend funcional de demostración del proyecto Pequitas, desarrollado con HTML5, CSS3 y JavaScript.

Tecnologías:
- HTML5
- CSS3
- JavaScript
- localStorage / sessionStorage

Estructura:
- index.html: estructura principal y vistas.
- css/styles.css: estilos, componentes y diseño responsive.
- js/data.js: datos de demostración y persistencia.
- js/components.js: componentes visuales reutilizables.
- js/navigation.js: navegación del panel.
- js/app.js: lógica principal e interacciones.
- assets/: logo, iconos y recursos visuales de productos.

Acceso de demostración:
Usuario: admin
Contraseña: 1234

Funciones principales:
- Navegación del sitio público.
- Inicio de sesión.
- Dashboard.
- Gestión de clientes.
- Gestión de mascotas.
- Gestión de veterinarios.
- Gestión de citas.
- Historial clínico.
- Catálogo de productos.
- Formularios con validación básica.
- Búsqueda de registros.
- Eliminación de registros.
- Persistencia de datos mediante localStorage.
- Diseño responsive para escritorio y dispositivos móviles.

Nota:
Este proyecto corresponde a un frontend académico funcional. No utiliza servidor ni base de datos externa; los datos se almacenan localmente en el navegador para demostrar la interacción de los componentes frontend.
